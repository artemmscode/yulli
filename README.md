# OUR STORY

Маленькое интерактивное приложение-подарок, сделанное одним человеком специально для другого.
Работает как Telegram Mini App и как обычный статический сайт. Без backend, без сборки, без зависимостей — только HTML, CSS и vanilla JavaScript.

---

## 1. Как открыть

Просто открой `index.html` в браузере (двойной клик по файлу).

На телефоне:
1. Закинь папку `our-story/` на хостинг (GitHub Pages, Netlify Drop, любой статический хостинг).
2. Открой ссылку на телефоне.

Музыка подгружается из `assets/audio/music.mp3`. Если файла нет — сайт просто работает без музыки, без ошибок.

---

## 2. Структура

```
our-story/
├── index.html        # все сцены
├── style.css         # все стили
```

## 3. Где менять имя и все тексты

Всё персональное находится **в одном месте** — в начале файла `script.js`, объект `APP_DATA`:

| Поле | Что меняет |
|---|---|
| `girlfriendName` | имя, которое подставляется в письмо (`Dear [ИМЯ],`) |
| `yourName` | твоё имя (для подписи) |
| `timeline` | даты и события на экране STORY |
| `memories` | фото и подписи на экране MEMORIES |
| `apology` | абзацы на экране извинения |
| `apologyEnd` | финальные строки перед кнопкой «Продолжить» |
| `puzzle` | вопросы MEMORY PUZZLE (`answers`, `correct` — индекс правильного ответа) |
| `letter` | абзацы письма |
| `letterSign` | подпись в конце письма |
| `letterPs` | строка `p.s. scroll a little more` |
| `final.loveMessage` | текст «Я очень тебя люблю.» |

Места с квадратными скобками (`[ИМЯ]`, `[ВОСПОМИНАНИЕ]`, `[ПЕРСОНАЛЬНЫЙ ТЕКСТ]` и т.д.) — это заглушки. Замени их на свои слова.

---

## 4. Где менять фотографии

Положи свои фото в `assets/images/` и переименуй в:
- `memory-01.jpg`
- `memory-02.jpg`
- ...
- `memory-06.jpg`

Либо поменяй пути в `APP_DATA.memories[i].image`. Если фото нет — вместо него показывается аккуратная заглушка, сайт не ломается.

---

## 5. Где менять музыку

Замени `assets/audio/music.mp3` на свой трек. Менять имя файла не обязательно, но можно — тогда поправь путь в `script.js` (функция `initMusic`, строка с `new Audio(...)`).

Сейчас там стоит романтичная классическая мелодия **«Classic Love Scene» — Steve Oxen** (Fesliyan Studios), royalty-free. Атрибуция уже добавлена в `script.js`. Если поставишь свою музыку — удали этот комментарий.

Музыка не запускается сама — девушка включает её кнопкой ♫ на первом экране.

---

## 6. Где менять цвета

Все цвета — CSS-переменные в начале `style.css`:

```css
:root {
    --bg: #0B0A0F;
    --accent: #E8A9B8;
    --accent-secondary: #BFA7FF;
    ...
}
```

## 7. Как подключить Telegram Mini App

1. В BotFather создай бота.
2. Отправь боту `/newapp` (или `Menu button` → web app), укажи URL твоего хостинга с `index.html`.
3. Добавь бота в чат с девушкой и пришли ссылку на Mini App.

Интеграция уже встроена в `script.js` (`initTelegram`):
- `tg.ready()` + `tg.expand()`
- haptic feedback на кнопках и свайпах
- системная BackButton (скрывается на START)
- учёт safe areas в CSS

Если открывать вне Telegram — сайт работает так же, просто без Telegram-фич. Никаких ошибок `Telegram is not defined`.

---

## 8. Перезагрузка и сброс

При каждой перезагрузке страницы сайт начинается заново (с экрана START) — так человек каждый раз проживает историю с начала. Сохранение прогресса между сессиями не используется.

Чтобы посмотреть сайт с начала вручную — открой консоль (`F12`) и выполни:

```js
window.resetOurStory()
```

---

## 9. Технические особенности

- Все переходы — кинематографичные, через `opacity` / `transform`, без рывков.
- Свайп в MEMORIES — чистый `touchstart/touchmove/touchend`, без библиотек.
- Фото preload: следующее загружается заранее.
- Поддержка `prefers-reduced-motion`.
- Никаких внешних библиотек и сборки.
